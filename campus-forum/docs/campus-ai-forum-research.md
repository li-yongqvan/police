# AI 智联论坛 MVP 说明

## 1. 产品目标

这版 MVP 不是为了把完整论坛一次做完，而是为了给学院级人工智能协会提供一个可以直接展示的社区原型。它需要同时回答三个问题：

- 学习交流内容如何组织
- 协会运营活动如何承接
- 中台如何用最小成本体现控制、监管和统计

## 2. 本次实现范围

已实现：

- 演示登录与角色切换
- 三大板块：AI学习交流区、协会公告&活动区、技术问答求助区
- 帖子列表、帖子详情、评论、点赞、精华展示
- 附件元数据展示：链接、图片、文档
- 中台数据概览
- 审核队列与通过/驳回
- 板块开关与发帖限制
- 用户封禁与恢复
- 基于敏感词的最小审核拦截

明确未做：

- 真实注册和 OAuth
- 私信、关注、积分等级
- 复杂搜索、分页、推荐
- PostgreSQL / Redis
- 直播、赛事报名、企业专区
- 高级风控与行为画像

## 3. 技术实现取舍

虽然需求文档中的远期方案是更完整的微服务和基础设施体系，但这次 MVP 为了快速演示，做了三项收缩：

1. 认证收缩为演示登录
2. 数据层收缩为共享 JSON
3. 服务调用保留 HTTP 关系，但不引入消息队列和数据库

这样做的好处是：

- 三个服务真实存在，能讲清系统拆分
- 页面和流程是活的，能直接演示
- 后续要接数据库时，接口边界不用推翻重来

## 4. 展示重点

最适合展示的故事线是：

1. 学生进入社区前台，感受到板块和技术讨论氛围
2. 学生发帖后触发审核逻辑
3. 管理员进入中台，处理待审核内容
4. 中台管理员调整配置，再回到前台验证变化

这条线既能体现社区感，也能体现“论坛 + 中台”的项目价值。
