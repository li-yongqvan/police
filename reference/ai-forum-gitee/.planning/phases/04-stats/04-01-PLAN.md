# Phase 4: 数据统计与报表 — Implementation Plan

## Goal
完成中台数据统计功能（注册用户数、日发帖量、板块活跃度），实现每日统计报表，完善中台数据展示面板。

## Requirements
- ANAL-01: 中台可查看核心数据概览
- ANAL-02: 中台可查看每日统计报表

## Success Criteria
1. 中台首页展示核心数据（注册用户数、日发帖量、板块活跃度）
2. 可查看按日的历史统计报表
3. 数据可视化展示（图表形式）

## Overview

This is a single-plan phase covering:
1. Database migration for `statistics_daily` table
2. Forum-service stats endpoint (internal API)
3. User-service stats endpoint (internal API)
4. Admin-service stats service + handlers (orchestration layer)
5. Admin frontend dashboard with ECharts charts

## Task Breakdown

### Task 1: Database Migration — statistics_daily table

Create migration `003_statistics.up.sql` and `003_statistics.down.sql` in `services/admin/migrations/`:

```sql
-- 003_statistics.up.sql
CREATE TABLE IF NOT EXISTS schema_admin.statistics_daily (
    id SERIAL PRIMARY KEY,
    stat_date DATE NOT NULL UNIQUE,
    new_users INT DEFAULT 0,
    new_posts INT DEFAULT 0,
    new_comments INT DEFAULT 0,
    active_users INT DEFAULT 0,
    total_users INT DEFAULT 0,
    total_posts INT DEFAULT 0,
    total_comments INT DEFAULT 0,
    board_activity JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMP DEFAULT NOW()
);
CREATE INDEX idx_statistics_date ON schema_admin.statistics_daily(stat_date);
```

Run migration via `migrate` CLI or the existing `database.RunMigrations` path.

### Task 2: Forum-service Stats Endpoint (Internal API)

**File: `services/forum/internal/service/stats_service.go`** (new)
- `GetOverview(ctx)` → returns total posts, total comments, total likes, posts today, top boards by post count
- `GetDailyPosts(ctx, days)` → returns array of {date, count} for last N days
- `GetBoardActivity(ctx)` → returns array of {board_id, board_name, post_count, comment_count}

**File: `services/forum/internal/handler/stats_handler.go`** (new)
- `GetStatsOverview` handler
- `GetDailyPosts` handler
- `GetBoardActivity` handler

**File: `services/forum/cmd/main.go`** — register routes:
```go
internal.GET("/stats/overview", statsHandler.GetStatsOverview)
internal.GET("/stats/daily-posts", statsHandler.GetDailyPosts)
internal.GET("/stats/board-activity", statsHandler.GetBoardActivity)
```

### Task 3: User-service Stats Endpoint (Internal API)

**File: `services/user/internal/service/stats_service.go`** (new)
- `GetOverview(ctx)` → returns total users, users today, users by level
- `GetDailyUsers(ctx, days)` → returns array of {date, count} for last N days

**File: `services/user/internal/handler/stats_handler.go`** (new)
- `GetStatsOverview` handler
- `GetDailyUsers` handler

**File: `services/user/cmd/main.go`** — register routes:
```go
internal.GET("/stats/overview", statsHandler.GetStatsOverview)
internal.GET("/stats/daily-users", statsHandler.GetDailyUsers)
```

### Task 4: Admin-service Stats Service (Aggregation + Daily Rollup)

**File: `services/admin/internal/service/stats_service.go`** (new)
- `GetOverview(ctx)` → calls forum + user internal APIs, aggregates response
- `GetDailyStats(ctx, days)` → reads from `statistics_daily` table, returns historical data
- `ComputeDailyStats(ctx, targetDate)` → scrapes user/forum services, writes to `statistics_daily`
- Uses existing `forumClient` and new `userClient` for internal API calls

**File: `services/admin/internal/handler/stats_handler.go`** — replace stubs:
- `GetOverview` → calls `statsService.GetOverview`, returns combined dashboard data
- `GetDailyStats` → calls `statsService.GetDailyStats`, returns historical chart data

**File: `services/admin/cmd/main.go`** — add daily stats computation cron-like job:
- On startup, compute stats for yesterday if missing
- Add simple in-memory ticker that runs at midnight to compute daily stats

### Task 5: Admin Frontend Dashboard with ECharts

**Install ECharts:** `npm install echarts --save`

**File: `frontend/src/views/admin/AdminDashboard.vue`** (new)
- Overview cards: 注册用户数、今日发帖、今日活跃用户、总帖子数
- ECharts line chart: 7日趋势（注册用户数 + 发帖量双Y轴）
- ECharts bar chart: 板块活跃度排行
- ECharts pie chart: 用户等级分布

**File: `frontend/src/api/admin.js`** — add:
```js
export function getStatsOverview() { return api.get('/stats/overview') }
export function getDailyStats(days) { return api.get('/stats/daily', { params: { days } }) }
```

**File: `frontend/src/router/index.js`** — add `/admin` route pointing to AdminDashboard

**File: `frontend/src/views/admin/AdminLayout.vue`** — add "数据统计" nav link

### Execution Order
Tasks 2 and 3 are independent (forum-service and user-service stats). Task 4 depends on Tasks 2+3. Task 5 depends on Task 4. Task 1 (migration) is prerequisite for Task 4.
