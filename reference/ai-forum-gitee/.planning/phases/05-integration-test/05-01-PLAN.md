# Phase 5: 集成测试与上线准备 — Plan

## Goal
完成端到端集成测试，验证所有用户流程，修复问题，准备上线部署。

## Requirements
- 验证所有 Phase 1-4 的已完成功能

## Success Criteria
1. 完整业务流程测试通过：注册→发帖→评论→审核→统计
2. 敏感词过滤功能正常拦截违规内容
3. 封禁用户后无法继续发帖
4. 移动端各页面适配正常
5. Docker Compose 一键启动全服务无报错
6. 数据报表与实际数据一致

## Task Breakdown

### Task 1: E2E API Integration Test Script

**File: `scripts/e2e-test.sh`** (new)

A bash script that tests all critical flows using curl:

1. **Register → Login flow**: Create invite code → Register → Login → Refresh token
2. **Post flow**: Create post (should go to pending_review if contains sensitive word, otherwise published) → List posts → Get post detail → Edit post → Delete own post
3. **Comment flow**: Create comment → List comments → Like post → Collect post
4. **Admin flow**: List pending audits → Approve post → Reject post → Ban user → Change user level
5. **Stats flow**: Get overview → Get daily stats
6. **Config flow**: Get config → Update config
7. **Invite flow**: Generate codes → List codes → Void code
8. **Board flow**: Create board → List boards → Update board → Delete board
9. **Sensitive words flow**: List → Add → Delete
10. **Role flow**: List roles → Assign role → Get roles

Each step checks HTTP status code and prints PASS/FAIL.

### Task 2: Docker Compose Validation

- Verify `docker-compose.yml` is valid with `docker compose config`
- Ensure no circular dependencies between services
- Check healthcheck definitions exist for all services
- Verify environment variable references match `.env.example`

### Task 3: Frontend Build Validation

- Run `npm run build` and verify output
- Check all admin routes resolve
- Verify no 404 on static assets
- Test responsive layout (check CSS media queries exist)

### Task 4: Deployment Documentation

**File: `DEPLOY.md`** (new)

Covers:
- Prerequisites (Docker, Docker Compose, PostgreSQL, Redis)
- One-command startup with `docker compose up -d`
- Manual service startup for development
- Environment variable configuration
- Database migration commands
- Nginx configuration notes
- Troubleshooting common issues
