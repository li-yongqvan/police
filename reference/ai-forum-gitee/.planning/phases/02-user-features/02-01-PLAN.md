```go
func RequireLevel(minLevel int) gin.HandlerFunc {
    return func(c *gin.Context) {
        level, exists := c.Get("level")
        if !exists { c.AbortWithStatusJSON(401, gin.H{"error": "unauthenticated"}); return }
        if level.(int) < minLevel {
            c.AbortWithStatusJSON(403, gin.H{"error": "权限不足，需要等级" + strconv.Itoa(minLevel)})
            return
        }
        c.Next()
    }
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API (via Nginx) | Untrusted input: registration data, post content, file uploads, all user-submitted content |
| forum-service → admin-service (internal) | Sensitive word check — trust internal network per D-09 |
| admin-service → user-service (internal) | Invite code generation — trust internal network per D-09 |
| File uploads → local filesystem | Potential for malicious files, path traversal |
| JWT tokens → client storage | Token theft enables impersonation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Spoofing | user-service /login | mitigate | bcrypt cost 12 password hashing, JWT HS256 with strong secret, refresh tokens in Redis only |
| T-02-02 | Spoofing | forum-service auth middleware | mitigate | Validate JWT signature on every protected route, check user status (banned=403) |
| T-02-03 | Tampering | POST /api/v1/posts, /comments | mitigate | Sensitive word check via admin-service before saving, author_id from JWT context not request body |
| T-02-04 | Repudiation | Post/comment creation | mitigate | Author ID derived from JWT claims, not client input — non-repudiable |
| T-02-05 | Information Disclosure | User profile, avatar paths | mitigate | UserResponse excludes password_hash, avatar paths served via download endpoint not direct filesystem |
| T-02-06 | Denial of Service | File upload endpoints | mitigate | Max file size 10MB images/20MB documents, validate MIME type not just extension, rate limiting via future middleware |
| T-02-07 | Elevation of Privilege | Level-based permissions | mitigate | Level extracted from JWT claims + verified against DB on sensitive operations, RequireLevel middleware on write endpoints |
| T-02-08 | Tampering | File upload path traversal | mitigate | Generate unique filename (timestamp+UUID), do not use client-supplied filename for storage path, validate MIME type server-side |
| T-02-09 | Spoofing | Invite code registration | mitigate | One-time use invite codes with status transition unused→used, atomic transaction for code consumption |
| T-02-10 | Information Disclosure | Internal service APIs (/internal/v1/) | mitigate | Nginx does NOT proxy /internal/v1/ to external clients (Phase 1 config), only accessible within Docker network |
</threat_model>
