# 参考仓库（只读）

本目录用于存放从 Gitee 拉取的 **AI 智联论坛** 后端设计参考代码，**不参与**主工程构建与运行。

**说明**：Gitee 参考版的前端（顶栏登录/注册、`/boards` 路由）已从本仓库移除；产品 UI 仅维护根目录 `frontend/`（学院演示版）。

| 路径 | 说明 |
|------|------|
| `ai-forum-gitee/` | 源仓库后端参考（无 `frontend/`）：<https://gitee.com/hebaonaodai/ai-forum> |
