> 日期：2026-07-31  
> 目标：确认当前最小可用版本能交给学生和运营人员试用。  
> 测试原则：只测试已开放的完整功能；隐藏功能只验证“入口不可见 / 不可误入”。

## 2. 测试前准备

### 2.1 测试地址

| 地址 | 用途 |
|---|---|
| `http://122.51.233.225:8888/` | 平台登录入口 |
| `http://122.51.233.225:8888/admin` | 平台管理后台 |
| `http://122.51.233.225:8080/` | Discourse 论坛 |
| `http://122.51.233.225:8080/admin` | Discourse 内容管理后台 |

注意：必须使用 `http://`，不要使用 `https://`。

### 2.2 测试账号

交接记录显示：服务器上所有用户密码已统一重置为 `123456`。  
建议准备至少 3 类账号：

| 账号类型 | 用途 |
|---|---|
| 学生账号 | 测登录、进论坛、发帖、回帖 |
| 协会管理员账号 | 测平台后台、用户管理、Discourse 管理入口 |
| 平台管理员账号 | 测邀请码入口是否可见 |

优先用以下环境各测一次：

| 环境 | 用途 |

## 3. 学生端测试

### S-01 登录页显示

步骤：

1. 打开 `http://122.51.233.225:8888/`。
2. 观察页面是否显示“AI 智联论坛”和“账号登录”。
3. 点击账号输入框和密码输入框。

预期结果：

- 页面可正常打开。
- 输入框可以稳定聚焦，不闪退。
- 登录页只显示账号密码登录。
- 不出现“邀请码注册”或“QQ 登录”入口。

### S-02 学生登录并进入论坛

步骤：

1. 在 `8888` 登录页输入学生账号和密码。
2. 点击“登录”。
3. 等待跳转。

预期结果：

- 登录成功。
- 页面自动跳转到 `http://122.51.233.225:8080/` 或 Discourse 相关页面。
- Discourse 内显示已登录状态。
- 不需要再次输入账号密码。

### S-03 浏览论坛

步骤：

1. 在 Discourse 首页查看主题列表。
2. 打开任意主题。
3. 返回列表。
4. 切换分类或最新主题列表。

预期结果：

- 主题列表能加载。
- 主题详情能打开。
- 页面返回和分类切换正常。
- 手机窄屏下文字、按钮、底部区域不遮挡。

### S-04 发帖

步骤：

1. 在 Discourse 点击“新建主题”或同等按钮。
2. 选择合适分类。
3. 输入标题：`测试主题 - MVP 验收`。
4. 输入正文：`这是一条用于试运行验收的测试主题。`
5. 发布主题。

预期结果：

- 主题可以成功发布。
- 发布后能进入主题详情页。
- 列表中能看到该主题。
- 作者显示为当前登录学生。

### S-05 回帖

步骤：

1. 打开刚发布的测试主题。
2. 点击回复。
3. 输入：`这是一条测试回复。`
4. 提交回复。

预期结果：

- 回复发布成功。
- 回复内容出现在主题下方。
- 刷新页面后回复仍存在。

### S-06 搜索和互动

步骤：

1. 使用 Discourse 搜索测试主题标题。
2. 对测试主题或回复进行点赞、收藏等操作。
3. 刷新页面。

预期结果：

- 搜索能找到测试主题。
- 点赞或收藏状态能保持。
- 如果某项互动因 Discourse 权限限制不可用，记录具体提示。

## 4. 管理端测试

### A-01 管理员登录

步骤：

1. 打开 `http://122.51.233.225:8888/`。
2. 使用管理员账号登录。

预期结果：

- 登录成功后进入 `http://122.51.233.225:8888/admin`。
- 页面显示“AI 智联论坛管理”。
- 管理首页显示“用户管理”和“Discourse 管理”。

### A-02 管理菜单检查

步骤：

1. 在桌面端查看左侧菜单。
2. 在手机端点击左上角菜单按钮。

预期结果：

- 普通管理员可见：管理首页、用户管理、前往 Discourse 管理。
- 平台管理员额外可见：邀请码。
- 不应看到：趋势统计、系统配置、角色权限。
- 手机端菜单能打开和关闭，文字不被遮挡。

### A-03 用户管理

步骤：

1. 进入 `http://122.51.233.225:8888/admin/users`。
2. 查看用户列表。
3. 翻页或刷新列表。
4. 选择一个专用测试账号，测试禁用和解禁。

预期结果：

- 用户列表能加载。
- 用户名、角色、状态等信息可读。
- 翻页或刷新正常。
- 测试账号可以禁用，也可以恢复。

注意：不要对真实用户或管理员账号做禁用测试。

### A-04 Discourse 内容治理入口

步骤：

1. 在平台管理后台点击“前往 Discourse 管理”。
2. 确认是否打开新标签页。
3. 在 Discourse 管理后台找到刚才发布的测试主题。
4. 尝试关闭、隐藏、删除或恢复测试主题中的一种低风险治理操作。

预期结果：

- Discourse 管理后台能打开。
- 管理员账号拥有内容治理权限。
- 能找到测试主题。
- 至少一种治理操作可用。

### A-05 邀请码管理

仅平台管理员测试。

步骤：

1. 登录平台管理员账号。
2. 进入管理后台。
3. 确认菜单中出现“邀请码”。
4. 进入邀请码页面，查看列表。
5. 如确实需要测试注册流程，再生成一个测试邀请码。

预期结果：

- 普通管理员看不到邀请码入口。
- 平台管理员能看到邀请码入口。
- 邀请码列表能加载。
- 生成或作废邀请码时有明确反馈。

注意：当前登录页隐藏注册入口，所以邀请码不是学生试运行必需功能。

## 7. 常见现象与判断

| 现象 | 判断 | 处理 |
|---|---|---|
| `400 Bad Request` | 多半是地址或协议不对，也可能是浏览器扩展/代理注入 | 确认使用 `http://122.51.233.225:8888/`，用无痕窗口重试 |
| `429 Too Many Requests` | 登录或接口请求过于频繁，触发限流 | 等待一段时间后重试 |
| 登录后没有进论坛 | SSO Cookie 或 token 可能异常 | 清理站点缓存后重新登录 |
| 8080 要求再次登录 | 可能是绕过了 8888 登录入口 | 先从 8888 登录，再自动跳转 |
| 管理后台用户列表失败 | admin-service 到 user-service 通信异常 | 记录时间、账号、截图和 Network 报错 |
| 手机端输入框失焦 | 可能是浏览器缓存、插件、输入法或页面刷新 | 用无痕窗口和另一台手机交叉验证 |

## 8. 通过标准

本轮 MVP 可交付测试通过，需要满足：

1. 学生能从 `8888` 登录并进入 `8080` 论坛。
2. 学生能浏览、发帖、回帖。
3. 管理员能从 `8888` 登录并进入管理后台。
4. 管理员能查看用户列表。
5. 管理员能进入 Discourse 管理后台处理测试帖子。
6. 登录页不暴露注册和 QQ 登录。
7. 管理后台不暴露趋势统计、系统配置、角色权限。
8. 手机窄屏下登录、菜单、发帖、回帖可用。
