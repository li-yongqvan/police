# AI 智联论坛 — 许岑式 Keynote（3 页）

## 关于「许岑」在本包中的角色

**许岑**（Keynote/PPT 设计大师）—「老罗背后的男人」，操刀锤子科技发布会、柴静《穹顶之下》等顶级视觉，著《征服世界的美学暴力》。

本目录**不是**让许岑本人出场汇报，而是按他的发布会美学，为 **AI 智联论坛 MVP** 写一套极简幻灯片：

- 屏上：**一个词 / 一行话**
- 嘴上：技术细节与进度（见 `speech.md`）

## 三页结构

| 页 | 屏上主词 | 含义 |
|----|----------|------|
| 1 | **智联** | 定调 · 项目名 |
| 2 | **论坛 + 中台** | 一击 · 做了什么 |
| 3 | **80%** | 落锤 · 进度 |

## 文件

| 文件 | 用途 |
|------|------|
| `outline.md` | 设计铁律 + 3 页意图 |
| `deck_spec.json` | 结构化规格（含 designer_persona） |
| `speech.md` | 口述稿（画面外的全部细节） |
| `AI_GENERATE.md` | 复制给 image AI 的 Prompt |

## 生成步骤

1. 打开 `AI_GENERATE.md`，按 3 条 Prompt 出图 → `origin_image/slide_01~03.png`
2. 用 codex-ppt `assemble_ppt.py` 合成 `.pptx`
3. 演讲时严格「看字说话、细节口述」— 这才是许岑式用法
