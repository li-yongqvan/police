## 第 1 页｜项目是什么

**幻灯片标题**：AI 智联论坛 — 项目概述

**正文要点**（页上文字，每条一行）：

- 面向学院人工智能协会的 **AI 主题社区论坛**
- 目标：支持发帖讨论、内容审核与基础运营管理
- 形态：**可演示、可部署** 的 MVP（最小可行产品）
- 用户：学生发帖互动；协会管理员审核运营；平台管理员配置治理

**口播补充**（可不写在页上）：解决学院内部 AI 话题分散、缺少统一交流与管理入口的问题。

**配图建议**：系统首页或登录页截图一张；若无图可用「社区 + 管理」示意图。

**幻灯片标题**：已完成工作

**正文要点**：

## 第 3 页｜进展与计划

**幻灯片标题**：当前阶段与下一步

**正文要点**：

- **当前阶段**：核心功能已完成，进入 **校内小规模试运行** 准备
- **近期工作**：公网 HTTPS 访问、消息通知、举报处理、界面优化、运维脚本
- **下一步**：内测 5～10 人验收 → 修问题 → 扩大试用范围
- **一句话收束**：从「能演示的 MVP」走向「可在校内试跑」

**口播补充**：风险与边界——不含即时私信、全文搜索等；先保证稳定与内容治理。

**配图建议**：简单时间轴（开发完成 → 试运行 → 灰度扩大）或 checklist 勾选示意。
