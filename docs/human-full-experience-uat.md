## 2. 情境说明（Kaner）

| 情境维度 | 本项目 | 对测试的影响 |
|----------|--------|--------------|
| 产品阶段 | MVP 校内试运行 | UI 小瑕疵可记 P3，但**权限与主路径**必须严 |
| 用户 | 学生 + 协会运营 + 中台 | 三角色各走一遍 |
| 规模 | 5～50 人 | 不做万级压测；可做 2 账号并发发帖观察 |
| 质量目标 | 可演示完整闭环 | 注册→发帖→评论→审核→管理 |
| 不测 | 全浏览器矩阵、极限压测 | 仅 Chrome + 1 款手机浏览器 |

**策略结论**：以**人工全路径 UAT** 为主，探索式补边界，攻击式验证安全，自动化仅作冒烟辅助。

## 3. 风险地图与探索章程（Bach）

### 3.1 风险地图（先测红的）

```
🔴 致命 — 必须测透
   垂直越权（学生进中台 / 调管理 API）
   水平越权（改 URL 看他人私密）
   存储型 XSS、未授权删帖
   Token/密码泄露

🟠 严重
   注册/登录/发帖/审核主流程中断
   邀请码滥用、恶意附件

🟡 中等
   通知不到达、收藏列表不一致、手机布局

🟢 低
   文案、配色、非关键动效
```

## 6. Web 输入安全矩阵（Offutt）

对每个输入：合法 → 边界 → 空/非法 → 安全 payload。记录**实际**与**预期**到反馈单。

| 输入点 `[P]` | 合法样例 | 边界 | 非法/空 | 安全 payload | 预期 |
|--------------|----------|------|---------|--------------|------|
| 邀请码 | DEMO2026 | 超长 200 字 | 空、错误码 | — | 拒/受控 |
| 用户名 | demo_new_01 | 1 字、64 字 | 空、特殊符 | — | 校验 |
| 密码 | Abcd1234 | 7 位 / 129 位 | 空、纯数字 | — | 强度 |
| 登录用户名 | demo_student | — | 不存在用户 | `' OR 1=1--` | 失败无泄露 |
| 帖标题 | 正常中文 | 500 字 | 空 | `<script>alert(1)</script>` | 不执行 |
| 帖正文 | 段落文本 | 超长 | 空 | `<img src=x onerror=alert(1)>` | 转义 |
| 评论 | 同上 | 同上 | 空 | 同上 | 同上 |
| 个人简介 | 一句话 | 超长 | 空 | XSS 串 | 不执行 |
| 搜索 q | AI | 空 | — | `'; DROP TABLE--` | 无 500 泄露 |
| 举报原因 | 广告 | 超长 | 空 | — | 接受/校验 |
| 附件名 | photo.jpg | 大文件 | 无文件 | `evil.exe` | 拒绝 |

## 7. 攻击式清单（Whittaker）

仅勾选**可复现**项并写入反馈单。

| □ | 攻击 | 做法 | 通过标准 |
|---|------|------|----------|
| | 存储型 XSS | 帖/评/简介注入 script | 不执行、不偷 cookie |
| | 垂直越权 | 学生 token 请求 `POST /admin-api/...` | 403 |
| | 水平越权 | 改 `users/:id` 或 API 中他人 id | 403/仅公开数据 |
| | CSRF | 无 token 跨站 POST（若可测） | 拒绝对未授权写 |
| | 恶意上传 | .exe / .php | 拒绝 |
| | 超大上传 | > 限制 | 明确错误 |
| | 登录爆破 | 连续错误登录 | 限流生效 |
| | 信息泄露 | 故意 404/500 | 响应无堆栈/SQL |
