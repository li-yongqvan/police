## 0.5 近期变更专项（最近一次部署）

### 0.5.1 板块解析修复（重点）

之前访问 `/community/boards/ai-learning`（AI 学习交流区 slug）会显示「该板块暂无帖子」，但侧栏明明写 3 帖。
原因：`useGxNav.js` 的 `resolveBoardByKey` 只认 `GX_NAV_ITEMS` 里写死的 key，找不到就 fallback 到 `boards[0]`，筛错板块。
现在改为：先按 `b.slug === key` 匹配，再走关键词兜底，都没有才返回 null。

- [ ] 直接打开 `http://122.51.233.225:8091/community/boards/ai-learning`
  - 预期：主区显示该板块的帖子列表（不再「暂无帖子」）
- [ ] 切换到 `/community/boards/tech-help`、`/community/boards/study`、`/community/boards/campus-circle`
  - 预期：每个板块帖子数与侧栏 `postCount` 一致
- [ ] 故意访问 `/community/boards/__no_such__`
  - 预期：显示「板块不存在或已下线」空态，而不是「该板块暂无帖子」
