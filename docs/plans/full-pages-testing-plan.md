# 全页面功能测试计划书

Date: 2026-08-14

> 接续 `docs/handoffs/handoff-2026-08-14-full-pages-testing-guide.md`。
> 本计划书定义本轮「Vue 轻前端 + Discourse 论坛」全页面测试的范围、顺序、门禁与交付物；测试账号、路径速查与坑位以该 handoff 为准，冲突时以 handoff 为最新依据。

## 1. Goal

对切换后的「Vue 3 SPA（登录 + 管理后台）+ Discourse（社区主体）+ SSO 打通」架构做一次完整的全页面验收，确认：

- 三类角色（学生 / 协会管理员 / 中台管理员）主流程闭环可用；
- 游客浏览路径可用；
- 移动端（390/375/320）与桌面（1440）均无页面级横向溢出、无空白关键控件；
- MUI-03A/04/05/06/07 已上线的默认主题（ID 1）改动不回退；
- 发现的问题按 P0-P3 分级记录并附截图与复现步骤。

## 2. Scope

### 2.1 测试范围

- Vue 端（:8888）：登录页、QQ 回调兜底页、管理后台框架与全部菜单页面。
- Discourse 端（:8080）：`/latest`、话题详情、`/categories`、`/c/ai/5`、`/top`、`/search`、`/new`、`/unread`、`/u/{username}` 系列、`/badges`、`/about`、`/faq`、`/tos`、`/signup`、`/login`、`/g`、`/chat` 与插件功能页、`/admin` 只读走查。
- SSO 打通：:8888 登录后按角色分流，学生自动跳转论坛。

### 2.2 回归基线（不回退）

本轮一切发现均不得以破坏以下基线为修复代价：

- MUI-03A：话题详情、回复/新建编辑器首轮移动端打磨，登录页视觉；
- MUI-04：搜索面板/结果页、汉堡菜单、用户菜单、通知、私信入口、分类页；
- MUI-05：话题详情底部动作区/时间轴、回复编辑器、新建话题编辑器；
- MUI-06：个人资料页活动导航四页签、用户卡片、帖子操作行、书签菜单、通知/账户面板、标签页；
- MUI-07：`/top` 时间范围选择器无溢出、字号 15px 完整显示、全表面 20 场景全绿。

### 2.3 明确非 Bug（勿报）

- `/register` 重定向回登录页；
- `/admin/stats|config|roles` 重定向；
- 登录/注册页装饰光球右侧略超视口（设计效果，无滚动影响）。

### 2.4 不测 / 降级测

- QQ OAuth 正常授权流程（依赖真实 QQ 授权环境），仅验证 `/oauth/qq` 异常兜底；
- Discourse `/admin` 仅只读走查，不做任何配置修改、备份恢复、主题同步操作；
- 私信内容不读（隐私红线），仅验证入口可达。

## 5. Strategy and Priorities

- 顺序：先游客只读路径，再学生闭环，再协会管理闭环，最后中台管理闭环；每阶段完成后先记录问题再进入下一阶段。
- 每场景固定记录：账号、页面地址、视口、亮/暗色、现象、复现步骤、预期/实际、截图。
- 功能测试优先于样式打磨：先确认流程走得通，再记录样式缺陷，避免被 UI 问题挡住主流程。
- 所有带副作用操作（发帖/回复/点赞/收藏/编辑/封禁/邀请码）只用演示账号执行，测完由管理员统一清理。

## 7. Acceptance Gates（硬门禁）

- 横向溢出：所有页面 `docOverflow=0` 且 `bodyOverflow=0`。脚本：

```js
Math.max(document.documentElement.scrollWidth, document.body.scrollWidth) - window.innerWidth
```

- 无页面级横向滚动条；登录页装饰光球为唯一豁免（设计效果）。
- 关键控件（搜索、导航、筛选、发帖、回复、上传、取消、发布等）亮色 + 暗色均有清晰文字或图标，不得出现视觉空白按钮。
- 触控目标不小于 40-44px。
- MUI-03A/04/05/06/07 回归基线全部不回退。
- 不出现 P0/P1 缺陷才视为本轮通过；P2/P3 进入排期清单。

## 8. Problem Severity and Feedback Format

| 等级 | 定义 | 处理 |
|------|------|------|
| P0 | 不可用或安全漏洞可利用 | 立即修 |
| P1 | 主流程受损，有绕行 | 本轮必修 |
| P2 | 次功能异常 | 排期修 |
| P3 | 体验/样式/文案 | 批量优化 |

反馈单必填：现象、复现步骤、预期结果、实际结果、截图路径、账号、设备宽度、亮/暗色；可选：HTTP 状态码、Console 报错（勿贴 token/cookie）。
## 9. Data and Privacy Red Lines

- CSS/样式验证期间不发帖、点赞、删帖、改用户数据；功能测试只用演示账号，测完由管理员清理。
- 不读 cookies、localStorage、令牌、密码、私信内容。
- 不做批量删文件、上传隐私文件、窃取账号类操作。
- Discourse `/admin` 只读走查，不改站点设置、不做备份恢复/主题同步。

- 生产环境测试会创建真实内容（发帖/回复/点赞），需管理员统一清理；若用户不允许在生产环境做功能测试，需切换到本地 Docker 环境重跑。
- 并行账号密码与用户名相同、旧文档密码信息不一致：以 handoff 为准，Phase 0 先验证。
- QQ OAuth 正常流程无法在本轮验证（缺真实 QQ 授权环境），仅覆盖异常兜底。
- 是否本轮立即执行测试：待用户确认后启动（默认：先交付计划书，用户确认后再走 Phase 0-6）。
