# AI 智联论坛 · 特色设计优化交接文档

> 面向：接手前端页面特色化设计的设计师 / 前端同学  
> 日期：2026-07-31  
> 当前阶段：MVP 试运行版，论坛已迁移到 Discourse  
> 核心要求：不做大改动，不破坏登录和发帖主流程，在现有稳定版本上增加自己的项目特色

---

## 1. 一句话理解项目

**AI 智联论坛**是一个面向学院学生的 AI 学习、交流与实践社区。

当前系统不是从零自研完整论坛，而是采用：

- `8888`：AI 智联平台入口，负责登录、SSO、少量平台管理
- `8080`：Discourse 论坛本体，负责帖子、回复、搜索、通知、内容治理

设计优化的目标不是“重做一个论坛”，而是让用户感受到：

> 这是一个有学院场景、有 AI 学习主题、有自己运营气质的校内论坛。

## 5. 本次设计任务目标

本次不是大型改版，而是做一版 **轻量特色化设计**。

### 5.1 设计目标

1. 让 8888 登录入口更像“AI 智联论坛”的官方入口。
2. 让管理员后台知道当前系统能做什么、不能做什么。
3. 让 Discourse 看起来不像默认开源论坛，而像校内 AI 社区。
4. 不影响登录、SSO、发帖、回帖、用户管理。
5. 移动端优先，保证手机窄屏可用。

### 5.2 成功标准

设计完成后，用户应该能一眼看出：

- 这是“广西警察学院 · AI 智联论坛”
- 这是围绕 AI 学习和实践的社区
- 学生知道登录后去哪里发帖
- 管理员知道在哪里管理用户和内容
- 页面不是默认 Discourse 风格，但仍保持稳定和克制

## 6. 建议设计方向

### 6.1 整体气质

推荐关键词：

- 校园
- AI
- 清爽
- 可信
- 实用
- 轻科技
- 移动端友好

不推荐：

- 大面积炫光渐变
- 复杂 3D 动效
- 营销式落地页
- 大量装饰卡片
- 重度暗黑科技风
- 完全复制 Discourse 默认样式

### 6.2 视觉建议

| 项目 | 建议 |
|---|---|
| 主色 | 稳定蓝色系，可保留学院/警院气质 |
| 辅助色 | 少量青色、绿色或金色，用于 AI、精选、提示 |
| 背景 | 简洁浅色或深蓝登录背景，避免花哨 |
| 卡片圆角 | 不超过 8px |
| 字体 | 中文优先清晰可读，不做负字距 |
| 图标 | 使用 lucide 图标，不自绘复杂 SVG |
| 动效 | 轻量 hover / focus，不做影响输入的动画 |

## 7. 页面级设计建议

## 7.1 8888 登录页

当前文件：

- `frontend/src/views/DemoLogin.vue`
- `frontend/src/components/gx/GxAuthShell.vue`
- `frontend/src/styles/gx-theme.css`

当前登录页只保留账号密码登录，这是正确状态，不要加回注册和 QQ。

建议优化：

| 区域 | 建议 |
|---|---|
| 主标题 | `AI 智联论坛` |
| 副标题 | `广西警察学院 AI 学习、交流与实践社区` |
| 标签 | `AI 工具交流`、`学习打卡`、`作品展示` |
| 表单提示 | `使用已发放的学号或用户名登录` |
| 底部说明 | `账号由管理员统一发放。如无法登录，请联系运营同学处理。` |

可以增加的特色：

- 背景加入轻微网格纹理或细线科技感
- 标题区加入学院和 AI 社区识别
- 登录按钮保持醒目，但不要过度装饰
- 手机端输入框高度稳定，点击后不能失焦

不要做：

- 不要加注册链接
- 不要加 QQ 登录按钮
- 不要加复杂轮播
- 不要让登录页变成营销落地页

## 7.2 8888 管理首页

当前文件：

- `frontend/src/views/AdminOverview.vue`
- `frontend/src/components/gx/GxAdminSidebar.vue`

| 区域 | 建议 |

- 一个小型“试运行状态”说明条
- 一个“当前开放能力”列表
- 一个“测试反馈建议”说明

不要做：

- 不要恢复趋势统计
- 不要恢复系统配置
- 不要恢复角色权限
- 不要做复杂数据大屏

## 8. 不要改动的核心链路

这些链路必须保持稳定：

```text
学生打开 8888
-> 输入账号密码
-> 登录成功
-> 自动跳转 Discourse SSO
-> 进入 8080 论坛
-> 浏览 / 发帖 / 回帖
```

```text
管理员打开 8888
-> 输入账号密码
-> 进入 8888/admin
-> 用户管理
-> 前往 8080/admin 做内容治理
```

涉及这些逻辑的代码不要随意修改：

| 文件 | 说明 |
|---|---|
| `frontend/src/router.js` | 登录后跳转、隐藏路由保护 |
| `frontend/src/stores/session.js` | 登录状态、用户角色、跳转目标 |
| `frontend/src/api/http.js` | token、cookie、401 刷新 |
| `services/user/internal/handler/discourse_sso_handler.go` | Discourse SSO |

如果确实需要改这些文件，必须先和项目负责人确认。

```bash

```

构建通过只是最低要求，还要做移动端截图检查。

## 11. 验收方式

### 11.1 必测页面

| 页面 | 地址 | 设备 |
|---|---|---|
| 登录页 | `http://122.51.233.225:8888/` | 手机 + 桌面 |
| 管理首页 | `http://122.51.233.225:8888/admin` | 手机 + 桌面 |
| 用户管理 | `http://122.51.233.225:8888/admin/users` | 桌面优先，手机可用 |
| Discourse 首页 | `http://122.51.233.225:8080/` | 手机 + 桌面 |
| Discourse 发帖页 | 论坛内新建主题 | 手机 + 桌面 |

### 11.2 必测动作

1. 点击登录页账号输入框，确认不会失焦。
2. 输入账号密码登录，确认能进入论坛。
3. 手机端打开登录页，确认按钮和输入框不溢出。
4. 管理员登录后进入 `/admin`。
5. 手机端打开管理菜单，确认文字不被裁切。
6. 直接访问 `/register`，确认不会进入注册页。
7. 直接访问 `/admin/config`、`/admin/roles`、`/admin/stats`，确认回到管理首页。
8. 在 Discourse 新建一个测试主题并回复。

### 11.3 不通过标准

出现以下任意情况，不能上线：

- 登录输入框失焦或页面反复刷新
- 学生登录后不能进入 Discourse
- 管理员登录后不能进入 `/admin`
- 手机端登录按钮或输入框被遮挡
- 隐藏功能重新出现在页面上
- Discourse 发帖或回帖主流程损坏

## 14. 给接手同学的建议

先做小而明确的特色化：

1. 统一品牌文案和视觉识别。
2. 优化登录页和管理首页。
3. 配置 Discourse 的站点名、Logo、主色和分类。
4. 写好置顶帖和发帖模板。

不要一上来重做论坛前端。当前最重要的是让试运行稳定，同时让用户感受到这是一个围绕校内 AI 学习场景设计的社区。
