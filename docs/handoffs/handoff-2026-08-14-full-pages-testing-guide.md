## 4. 页面总清单 A：Vue 端（:8888）

### 4.1 登录页 `/`
- 功能：学号/用户名 + 密码登录；提交后按角色分流（见第 3 节）。
- 测试点：空值校验、错误提示、loading 状态、成功跳转；390/375px 无横向溢出；暗色模式可读。登录页装饰光球（orb）右侧略超出视口属设计效果，无滚动影响，勿报。

### 4.2 QQ 登录回调 `/oauth/qq`
- 功能：接收 QQ 授权回调参数、写入会话并跳转；异常时展示错误并允许返回登录。
- 测试点：仅验证异常兜底（如缺 token 时提示），正常流程依赖真实 QQ 授权。

### 4.3 管理后台框架 `/admin`（AdminLayout）
- 功能：顶栏（菜单按钮/品牌/退出）+ 抽屉式侧边栏。
- 侧边栏菜单：管理首页、用户管理、（中台管理员额外）邀请码、（外链）前往 Discourse 管理 → `:8080/admin`。
- 测试点：窄屏抽屉开合、遮罩点击关闭、路由高亮、退出回登录页；低高度横屏时文案收缩（52px 顶栏）。

### 4.4 管理首页 `/admin`
- 功能：三个入口卡片——用户管理、邀请码（仅中台管理员可见）、Discourse 管理（外链）。
- 测试点：角色可见性（协会管理员看不到邀请码卡片）、卡片响应式网格、外链新窗口打开。

### 4.5 用户管理 `/admin/users`
- 功能：用户列表（20/页分页）、汇总卡（总数/当前页/正常/异常）、封禁/解封、修改等级（0–5）、查看用户操作日志。
- 测试点：分页边界（首页禁用上一页）、封禁后徽章状态变化、等级修改提示、日志区内容；窄屏按钮排布不溢出。

### 4.6 邀请码 `/admin/invites`（仅中台管理员）
- 功能：生成单个邀请码、批量生成（1–50）、按码查询状态、列表展示（可用/已用/作废）、作废操作。
- 测试点：批量数量边界（min 1 / max 50）、生成后列表刷新与 flash 提示、作废后状态更新、空查询不报错。

### 4.7 已下线/未挂载页面（勿当 bug）
- `/admin/stats`、`/admin/config`、`/admin/roles` 均重定向回管理首页（有意下线）。
- 源码中 `Register.vue`、`AdminConfig.vue`、`AdminRoles.vue` 未挂路由，属历史遗留，页面不可达是预期行为。

## 10. 哪些坑不要踩

- PowerShell 5.1：写文件用 UTF-8 无 BOM + LF（`[System.IO.File]::WriteAllText` + `UTF8Encoding($false)`）；`Get-Content` 默认 GBK，读 UTF-8 文件加 `-Encoding UTF8`。
- 远程 SSH：外层单引号、内层 `''`，避免 `#`、`$`、双引号被吃掉；复杂脚本走 scp + docker cp。
- 服务器：`ssh liyongquan@122.51.233.225`（密钥直连，有 Docker 权限）；Discourse 容器名 `app`。
- 主题改动流程：先 `discourse-themes/tools/backup-theme1.ps1` 备份，再用 `sync-field.ps1` 同步，等 digest 传播后再验证（详见 runbook）。
- 数据库：Discourse 自带 PG 与 `ai_forum` 的 PG 是两套；`reference/ai-forum-gitee` 是历史代码，勿当现役。
- Git：提交前 `$env:DEV_RECORD_SKIP='1'`；每 Ticket 一次 commit（`<type>: <description> (#Ticket)`）并立即 push `codex/discourse-rebuild`；严禁直接动 master。
- 隐私红线：不读 cookies/localStorage/令牌/私信内容；不做批量删文件、上传隐私、窃取账号类操作。
- 勿当 bug：`/register`、`/admin/stats|config|roles` 重定向是设计行为；登录页 orb 超边是设计效果。
