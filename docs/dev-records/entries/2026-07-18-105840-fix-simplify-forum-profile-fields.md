## Context

User pointed out that the current profile form collected department, squad, and grade, which is too much for an internal organization forum. The desired direction is closer to common forums: avatar, display name, username, and short bio, without making users fill organizational metadata.

## Outcome

Removed department/squad/grade collection from profile editing and registration. Profile save no longer submits those fields, onboarding prompts were removed, public profiles no longer show organization chips, and display-name formatting no longer prefixes squad. About-page registration guidance now describes setting avatar, nickname, and bio instead of filling department details.

Validated with `npm run build` in `frontend`. Desktop 1440px and mobile 390px visual checks confirmed that profile fields are limited to nickname, username, bio, and avatar, with no horizontal overflow.

## Follow-ups

- Backend fields remain for compatibility with existing rows, but the frontend no longer collects or displays them.
- The unrelated untracked `services/user/migrations/009_qq_number_login_accounts.up.sql` remains untouched.
