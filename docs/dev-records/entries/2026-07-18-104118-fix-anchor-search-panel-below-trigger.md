## Context

User confirmed the desired search overlay behavior from a mockup: the search panel should open directly below the top search trigger, not as a centered desktop modal or mobile bottom sheet. Mobile layout also needed verification.

## Outcome

The site header search controls now expose a shared `data-search-trigger` anchor. `GxSearchPanel` reads the visible trigger position on open, resize, and scroll, then sets CSS variables for an anchored dropdown. Desktop aligns the panel with the search bar and shrinks it instead of shifting left when the right edge is tight. Mobile opens a top dropdown below the search icon with 12px side margins, replacing the previous bottom sheet.

Validated with `npm run build` in `frontend`. Automated visual measurements:
- Desktop 1440px: panel left delta `0`, top gap `4px`, no horizontal overflow.
- Mobile 390px: panel left `12px`, width `366px`, top gap `8px`, no horizontal overflow.
