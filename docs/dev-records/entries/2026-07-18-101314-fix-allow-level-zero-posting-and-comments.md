## Context

User reported that some low-level users could not comment or publish posts, while these should be baseline community capabilities. Investigation found that forum-service routes required `RequireLevel(1)` for both post creation and comment creation, but new users default to Lv.0. Existing admin seed config also set post/comment minimum levels to `1`.

## Outcome

Post creation and comment creation now require level `0`, allowing default users to participate. Attachment upload was aligned to level `2`, matching the admin config and frontend copy. Admin config writes enabled posting as `post_requires_level = 0`, the initial admin seed now defaults post/comment requirements to `0`, and migration `007_allow_level_zero_post_comment` updates existing deployments from `1` to `0`.

Validated with `go test ./...` in `services/forum`, `go test ./...` in `services/admin`, and `npm run build` in `frontend`.
