## Context

User reported that pressing `Ctrl` alone could open the search panel, which made desktop usage inconvenient. Investigation found `onKeyStroke(['Control', 'k'], ...)` and `onKeyStroke(['Meta', 'k'], ...)` in `GxSearchPanel.vue`; in this usage the key array listens for either key rather than a strict key combination, so `Control` by itself could trigger the panel.

## Outcome

Removed the desktop keyboard shortcut handlers for search opening/toggling. `Escape` still closes the search panel when it is already open, and mouse/touch clicks on the header search trigger continue to open search. Updated the desktop search button copy from `Ctrl+K` to `搜索` so the UI no longer advertises a disabled shortcut.

Validated with `rg` to confirm no `Ctrl+K`, `ctrlKey`, `metaKey`, or search shortcut handlers remain in `frontend/src`, and with `npm run build` in `frontend`.
