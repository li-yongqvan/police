## Context

User reported that a changed profile avatar disappeared after refreshing the page. Investigation showed three weak points: profile image selection could remain only as a local preview if the user saved the form without clicking the separate upload button, the app reused cached `ai-forum-user` data on refresh without hydrating `/users/me`, and uploaded files needed an explicit persistent Compose volume.

## Outcome

The app now refreshes the current user once on startup when a token exists, profile save uploads a pending avatar before persisting the session, the avatar upload API can consume a full user payload, user-service returns the full user JSON after avatar upload, and `/data/uploads` is mounted as a named Docker volume.

Validated with `npm run build` in `frontend` and `go test ./...` in `services/user`.
