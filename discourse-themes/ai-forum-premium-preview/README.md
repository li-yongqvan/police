# AI Forum Premium Preview

这是 AI 智联论坛当前使用的 Discourse 主题预览包。

## 文件位置

- `about.json`：主题元数据和 Light / Dark 色板
- `common/common.scss`：全站通用样式
- `desktop/desktop.scss`：桌面端微调
- `mobile/mobile.scss`：移动端微调

## 适用范围

该主题只作用于 `8080` 的 Discourse 论坛界面，不影响 `8888` 登录入口和当前前端工程。

## 使用指南

### 1. 进入论坛

先通过 `8888` 登录入口完成登录，系统会跳转到论坛主页。

### 2. 浏览内容

- 在首页查看最新话题和分类
- 点击话题标题进入详情页
- 使用顶部搜索查找帖子、用户或分类

### 3. 发帖

1. 进入目标分类
2. 点击发帖按钮
3. 输入标题和正文
4. 需要时可插入图片、引用、代码块
5. 发布后可在自己的帖子里继续编辑

### 4. 回复

- 在帖子底部直接回复
- 支持引用回复
- 可通过编辑按钮修正已发布内容

### 5. 通知与个人设置

- 点击右上角头像查看通知、消息和个人资料
- 可在个人设置里切换主题、明暗模式和界面偏好

### 6. 移动端使用

- 手机浏览时优先使用底部或顶部的主要操作入口
- 发帖时注意键盘弹出后的输入区域
- 若界面显示为暗色或亮色，可在个人设置中切换

## 导入说明

如果需要在 Discourse 后台使用这套主题：

1. 打包该目录或使用仓库导入
2. 在 `Customize -> Themes` 中导入
3. 绑定对应的 Light / Dark 色板
4. 先用预览模式检查，再决定是否设为默认主题

## 回滚

如果主题显示异常，直接切回原主题即可。
